# ElecMole 공포 음향 설계 — 0.8.0

## 분위기와 정보 전달

폐건물과 낡은 전기기기가 평소에는 익숙하게 들리다가 위협으로 바뀌는 소리를 기준으로 삼았다. 밝은 보상 팡파르·멜로디 대신 짧은 기계음, 마모된 금속, 아날로그 정전기, 낮은 공기 진동을 사용한다. 음성 대사·타인의 음원은 사용하지 않았다.

상시 배경음은 낮은 환기·험·테이프 질감이다. 우주선에서는 이를 낮추고 별도의 실내 기계음을 섞는다. 건물에서는 24~48초 간격으로 금속 울림·무전 잡음·긁힘·덕트 공기 소리 중 하나가 7~13m 떨어진 곳에서 들린다. 이 소리는 실제 적의 발견음과 분리해 만들었으며 적 위치나 게임 규칙을 변경하지 않는다. 사망·우주선 내부에서는 간헐적인 공포음을 새로 시작하지 않는다.

괴물의 발견음은 인지 유예와 함께 시작한다. 돌진과 타격은 별개의 음원이다. 큰 파괴·발견·돌진·충격 때 배경음은 1.5초간 낮아져 중요한 신호가 묻히지 않게 한다. 적·간헐적 공포음의 최소 감쇠 거리를 일반 효과음보다 길게 잡았다.

## 생성과 출처

ElevenLabs Sound Effects v3에서 35회 생성했다. 각 생성의 여러 후보 중 하나를 저장했다. 비공개 생성, 기존 잔액 8,569 → 5,891, 사용량 2,678크레딧. 추가 구독·크레딧 구매·공개 게시를 하지 않았다. 총 길이는 약 93.95초다.

`ElevenLabsManifest.json`에 각 키, 프롬프트 검색어, 원본 파일명·선택된 후보 번호, 원본 SHA-256, 출력 경로, 길이, 적용 게인, RMS·피크와 반복 여부를 기록했다. 원본 MP3를 44.1kHz 모노 PCM WAV로 변환하고 RMS와 피크를 분석해 정규화했다. 최대 피크는 -1.5dB다. Unity에서는 Vorbis 품질 0.8로 임포트하며, 긴 배경음은 스트리밍하고 짧은 효과음은 미리 로드한다.

## 재생 비용과 믹스

효과음 소스 32개와 반복 소스 4개를 재사용한다. 같은 이벤트가 45ms 안에 쌓이지 않게 제한한다. 먼 소리는 생략하고, 월드 소리는 로그 거리 감쇠를 적용한다. 차폐된 소리는 볼륨을 절반으로 낮추고 1.8kHz 저역 통과 필터를 적용한다. 짧은 UI 효과는 플레이어 가까이에서 2D로 들린다. 기본 보이스 게인은 0.68이다.

배경음과 원샷은 별도로 제어한다. 소리는 권위 있는 게임 상태를 바꾸지 않으며 게임플레이 RPC로 오디오 샘플을 보내지 않는다. 발소리·공간 배경음은 각 참가자의 표현이다.

## 검증 범위

35개 리소스 존재·길이·무음/피크 검사, 실행 중 배경음·버튼음·염력음, 별도 호스트/클라이언트의 발견 상태와 생성 음원 로드를 확인했다. 전체 음원의 주관적인 청취 평가, 다양한 헤드폰·스피커의 최종 믹싱과 두 물리 PC의 장시간 플레이는 남아 있다. 생성 파일 수만으로 모든 미래 콘텐츠의 소리가 완성됐다고 간주하지 않는다.
