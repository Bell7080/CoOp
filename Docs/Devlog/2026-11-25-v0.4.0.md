# v0.4.0 개발 로그 — 2026-11-25

이전 버전: 0.3.0

## 목표

ElecMole 2단계: 염력·전선 운반과 가치, 인벤토리, 시체 오브젝트와 유령 관전, 우주선 탈출 부활, 감시실식 CCTV(지도·카메라 조명·곡면 화면), 무전 게임 상태, 2프로세스 자동 E2E 테스트.

## 변경

- 염력 운반(Grabbable): 충전된 가전을 좌클릭 꾹으로 띄워 옮긴다. 무게(TV·전자레인지 2명)가 모자라면 바닥으로 끌기만 된다. 우클릭 꾹+마우스로 회전. 방장 물리 + NetworkTransform/NetworkRigidbody 동기화.
- 전선 플러그(CordPlug): 플러그를 뽑아 들고 송신구 소켓에 꽂는다. 전선 길이(4.5~6m)를 넘기면 가전이 끌려오며 긁혀 가치가 깎이고, 너무 당기면 손에서 빠진다. 정산 때 꽂힌 가전이 전선을 따라 빨려 들어간다.
- 가치: 부딪힘·끌림·괴물 공격으로 깎인다. 송신구 예상 정산 금액과 탈출 화면의 정산 금액 표시.
- 인벤토리 1칸(숫자 키): 초소형 가전(라디오·토스터)을 보관했다가 꺼내 든다. 슬롯 수는 이후 상점 모듈로 늘린다.
- 사망: 별도 시체 오브젝트(PlayerCorpse 프리팹, 방장 스폰). 죽은 플레이어는 보이지 않는 유령으로 산 동료를 관전(좌/우클릭 전환). 시체 연타로 부활, 시체를 염력으로 옮길 수 있고 우주선 안 시체는 출발 직전 체력 50으로 부활. 개발 샌드박스 씬도 같은 규칙이고 전원이 죽으면 3초 뒤 전원 부활.
- 출발: 버튼 뒤 10초 카운트다운, 살아 있는 전원이 타면 3초.
- CCTV 재작업: 우주선 기점 경로가 이어지는 지도와 켠 카메라 버튼, 카메라마다 조명(CCTV 렌더에서만 켜짐), 둥근 브라운관 곡면 화면과 베젤, 약한 노이즈와 전환 시 지직임, 커서 모드(화면 끌기 회전, 휠 확대, 지도 클릭, Q·Tab·Esc·우클릭 종료).
- 무전(E, 게임 상태만): 밖에서는 무전기를 들어 우주선 스피커로, 우주선 방송 마이크를 보고 누르면 전원에게. 청취 규칙은 VoiceRouting, 송수신 HUD와 딸깍 소리. 실제 음성 전송은 아직 없다.
- 자동 E2E 테스트: Assets/_Game/Scripts/Testing/ElecMoleE2E.cs(에디터·개발 빌드 전용 자동 조작) + tools/e2e-elecmole.ps1(MPPM 시나리오 실행, 단계별 검증, 화면 캡처, Logs/E2E 보고서).
- RoomLimits.ProtocolVersion 3→4. 기획 문서에 인벤토리·무전·탈출·CCTV 답변 반영, Docs/VOICE.md에 무전 규칙 추가.

## 검증과 결과

- 메인 에디터 재컴파일 오류 0. 씬 빌드 후 NetworkObject 25개 해시 중복 없음, 플레이어 프리팹 누락 스크립트 0, 두 씬 NetworkManager에 네트워크 프리팹 목록 등록 확인.
- tools/e2e-elecmole.ps1: 메인 에디터(방장) + MPPM Player 2(별도 프로세스), Relay 방 생성·참가 후 42단계 전부 통과 3회 연속(마지막은 0.4.0 버전 반영 후). 발전기와 스킬체크, 실패 시 정지와 괴물 소음 조사, 우주선 문, CCTV 전력과 관람(지도 버튼), 송신구 활성화, 염력 운반·전선 끌기(가치 150→141)·인벤토리 운반, 정산·암전(CCTV 방전), 무전 송신, 사망·유령 관전·연타 부활(8대, 체력 1), 시체 운반·출발·출발 직전 부활(체력 50)·탈출.
- E2E 화면 캡처로 스킬체크 UI, CCTV 곡면 화면·조명·지도, 유령 관전 화면 확인.

## 남은 항목

- 사람이 직접 마우스·키보드로 해 본 확인은 아직이다. 자동 테스트는 같은 상호작용 코드 경로를 쓰지만 우클릭 회전, 지도 버튼 클릭, 화면 끌기는 자동 테스트에 없다.
- 무거운 가전 2인 들기, 플러그가 끌리다 빠지는 경우, 운반 중 괴물에게 맞는 경우는 E2E에 없다. E2E에서는 괴물을 얼려 두고 소음 반응만 확인한다.
- 들고 가는 물건이 문틀에 걸려 놓칠 수 있다(E2E는 다시 집어서 진행).
- 실제 음성(마이크 캡처·전송·재생)은 없다. 두 실제 PC 테스트와 Windows 빌드는 하지 않았다.
- 정산 금액은 마지막 소켓을 채운 순간 꽂힌 가전의 가치 합이다. 수치는 모두 임시값.

## 테스트 방법

1. 자동: 에디터를 열고(플레이 모드 끔) `.\tools\e2e-elecmole.ps1`. 보고서와 캡처는 `Logs/E2E/<시각>/`.
2. 직접: `ElecMolePrototype` 씬, 방 만들기(+친구 또는 MPPM 참가).
   - 발전기(좌클릭 꾹, Space 스킬체크) → 우주선 문 → 밖의 CCTV 전원함 → 우주선 모니터 좌클릭(지도 버튼, 화면 끌기, 휠 확대, Q로 나가기).
   - 북동쪽 송신구 활성화 → 가전 충전 → 좌클릭 꾹으로 들기(우클릭 꾹+마우스 회전) 또는 플러그 좌클릭 후 송신구에 좌클릭. 라디오·토스터는 든 채로 1을 눌러 보관, 다시 1로 꺼내기.
   - 3개를 꽂으면 정산·암전 → 우주선 출발 버튼. 둘이면 한 명이 죽어서 유령 관전, 다른 사람이 연타 부활 또는 시체를 우주선으로 옮긴 뒤 출발.
