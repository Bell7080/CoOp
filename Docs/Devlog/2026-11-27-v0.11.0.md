# v0.11.0 개발 로그 — 2026-11-27

이전 버전: 0.10.0

## 목표

자명종 거미 벽·천장 이동, 천장 낙하 공격, 머리에 매달리기

## 변경

- 자명종 거미가 바닥부터 천장까지 이어진 벽(문·장애물 없음)을 찾아 올라가고 내려옴: 둥근 안쪽 모서리를 돌며 몸이 표면 법선을 따라 회전 (TempMonster.Climb.cs)
- 천장 경로탐색: 바닥 NavMeshAgent를 그림자로 두고 그 위 천장에 매달려 이동, 린텔·파이프 높이에 맞춰 내려오고 기울어짐. 천장 20~40초, 바닥 6~16초 체류
- 천장 낙하 공격: 3m 안 아래 타깃에게 0.45초 정지(틱 멈춤·삐걱) 뒤 공중에서 뒤집히며 낙하, 닿으면 매달림, 빗나가면 1초 기절. 스턴·사망 시 천장에서 떨어지고 배터리는 바닥에 드랍
- 거미가 등 대신 머리에 매달림(0.6배): 피해자 1인칭 화면 위·옆으로 다리가 보이도록 카메라 렌더 직전에 배치
- 거미만 NetworkTransform X/Z 회전·쿼터니언 동기화(런타임 적용, 씬 재빌드 불필요), RigAnimator 몬스터 속도에 수직 이동 포함
- RoomLimits.ProtocolVersion 7 -> 8 (거미 낙하 RPC·회전 동기화)

## 검증과 결과

- Unity 6000.3.29f1 batchmode 재컴파일 오류 0
- 실제 플레이 확인은 우성이 직접 진행 예정, 2인 별도 프로세스 E2E는 미실행

## 남은 항목

- 벽을 따라 옆으로 기는 이동은 미구현(벽은 위아래로만)
- 머리 매달림 화면 위치(높이·기울기·크기)는 플레이 피드백으로 조정 필요
- 천장 아래 1.2m 가량 내려오는 몸 콜라이더에 키 큰 플레이어가 부딪힐 수 있음
