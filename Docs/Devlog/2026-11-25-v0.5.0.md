# v0.5.0 개발 로그 — 2026-11-25

이전 버전: 0.4.0

## 목표

ElecMole 3단계: 새 맵과 CC0 소품, Tripo 캐릭터·괴물과 Blender 애니메이션, 어둠·손전등·숨기, 전력 연동 우주선 조명과 문

## 변경

- 맵 재구성: 72x56m 12개 방(우주선·창고·보일러실·숙소·사무실·휴게실·서버실·송신실 등), 32px 점 필터 텍스처, 숨을 수 있는 책상·침대 밑 공간.
- CC0 로우폴리 에셋(Kenney Furniture/Factory/Space Station/City Industrial, Quaternius Zombie/House/Sci-Fi)으로 소품 178개 교체. 충돌·NavMesh는 기존 블록아웃 그대로. 쓰는 모델만 Assets/_Game/ThirdParty에 라이선스와 함께 포함.
- Tripo(유료 크레딧, 상업 이용 가능) 모델 3종: 두더지 외계인 플레이어, TV 괴물, 선풍기 괴물. Blender 자동 리깅·애니메이션(tools/blender). RigAnimator가 이동 속도·웅크림·추격 상태로 클립 재생, 코·팔 출렁임.
- 두더지 외형: 몸은 플레이어 색(콘셉트 8색 팔레트), 코는 몸 색의 채도 낮춘 색+가로 줄무늬, 하이라이트 눈, 피부에 붙은 볼터치. 출렁임·찌그러짐 완화.
- 설치 장치 뜯어 팔기: CCTV 카메라·충전식 조명을 길게 눌러 떼면 판매용 부품이 나온다(소음 발생).
- 운반 개선: 떨어뜨림·충돌 가치 하락, 무거운 물건 처짐, 플레이어와 물건 사이 전류 빔, 놓은 전선이 줄자처럼 감겨 돌아감.
- Ctrl 웅크리기와 가구 밑 숨기. 괴물 시야 120도, 추격 중 시야 밖에서 웅크리거나 엄폐물 뒤에 숨으면 약 1.2초 뒤 추격 해제.
- 어두운 PS1 화면(낮은 렌더 스케일, 디더링), 강한 손전등(밝기 24, 45m). 평소 주변광 소폭 상향.
- CCTV: PS1 효과 없는 전용 렌더러, 감마 보정, 야간 보조광, 방 중앙을 보도록 기본 방향 보정. 모니터를 가리던 우주선 기둥 제거.
- 우주선 조명: 공용 전력 30/50/70/100%에 따라 단계적으로 밝아지고 어두워짐. 처음엔 발전기 불빛만.
- 우주선 문: 한 번 전력을 채운 뒤 좌클릭으로 여닫기, 열림·닫힘 모두 공용 전기를 조금씩 소모, 전기가 없으면 조작 불가.
- Player 2는 F1 개발 도구 버튼으로만 실행(일반 Play는 메인 에디터만).

## 검증과 결과

- 메인 에디터 재컴파일 오류 0, 씬 재빌드 후 NetworkObject 82개(해시 중복 없음), NavMesh 우주선→각 방 경로 7개 모두 완료.
- 에디터 렌더로 소품 방향·색, 캐릭터 3종 배치·크기·클립, 두더지 색·볼터치 위치, CCTV 8대 화면, 우주선 전력 단계별 밝기 확인.
- 자동 E2E는 새 맵에서 49단계 통과(v0.5 초기, 외형·조명·괴물 시야·문 변경 이전). 이후 변경분은 E2E를 돌리지 않았다.
- 사용자 직접 플레이로 맵 밝기·CCTV·두더지 외형 피드백 반영. 괴물 시야 규칙·문 여닫기·문 전기 소모는 아직 사람이 해 보지 않았다.

## 남은 항목

- 죽었을 때 남는 시체와 시계 거미 괴물은 아직 도형 모델이다.
- 시체 부활 연타 때 NetworkBehaviour 미스폰 RpcException이 콘솔에 남은 적이 있다(기존 문제).
- 두더지 달리기 일부 프레임에 약한 주름이 남는다.
- 두 실제 PC 간 테스트는 아직이다.
