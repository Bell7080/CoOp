# v0.7.0 개발 로그 — 2026-11-26

이전 버전: 0.6.2

## 목표

시야·CCTV 레이더·물건 가치와 파손 피드백 개선

## 변경

- 우주선 접합부 잔해가 실내 벽면을 넘지 않도록 바운드로 제한
- CCTV 1280x960, 미리보기 320x240 및 부드러운 샘플링; 맵을 실제 투시 캡처한 레이더와 스캔/형광 필터
- 근처 물건에 큰 가치 표시와 붉은 감소 숫자, 가치 0에서 서버 권한 파손 상태 및 재사용 파편/파열음
- 바라보는 충전 대상에 가려짐을 지키는 얇은 외곽선
- 중앙 필터 강도 완화와 주변 비네트; 기본 18m, 손전등 중앙 38m 암흑 시야; 원거리 안개 완화
- 아이템 파손 동기화 추가로 프로토콜 5 적용

## 검증과 결과

- 컴파일·셰이더·런타임 화면·별도 프로세스 파손 동기화 집중 검증 통과 (아래 세부 결과 참고)

## 남은 항목

- 전체 E2E, 실제 두 PC와 저사양 성능 측정은 미실시
- 기존 전체 E2E의 선풍기 복도 운반 실패는 별도 미해결

## 다음 작업

- 위 남은 항목을 확인하고 다음 변경 전 관련 문서를 읽는다.

## 최종 검증 결과

- Unity 6000.3.29f1에서 C# 컴파일 통과. ChargeOutline, RadarCRT, FracturePiece의 ShaderUtil 메시지 수가 모두 0개였고 실제 렌더도 확인했다.
- Relay의 별도 호스트·참가자 프로세스 2개가 연결됐다. 참가자가 ServerDamage를 호출해도 가치가 200에서 바뀌지 않았다. 방장이 손상시킨 값 200→150은 두 프로세스에 동일하게 나타났다.
- 가치 0에서 호스트/참가자 모두 Broken=true, IsGone=true를 확인했다. 홀더 0명, 플러그 Stowed, 참가자의 활성 콜라이더 0개도 확인했다.
- 최종 파편은 흰 큐브 대신 원래 메시·UV·재질을 GPU 셀 클립으로 분할한다. 텍스처가 유지된 선풍기 조각이 튀는 순간을 캡처했다. 충전 외곽선은 6 mm·알파 0.6으로 낮추고 가격을 안내문 위로 분리했다.
- 재시작 후 레이더 카메라가 CctvView 월드 루트 아래 (0,52,-30)에 위치하고 실제 방/복도와 가구를 투시로 보여 주는 것을 확인했다. UI 좌표의 영향을 받던 첫 구현은 수정했다. 연결된 카메라 구역만 표시하고 동료/위험 신호는 같은 투시 좌표로 투영한다.
- 레이더 렌더 후 지붕의 enabled 상태와 안개 설정이 복구됨을 확인했다.
- 손전등 전/후 동일 위치 비교에서 근처의 형태는 계속 읽히고, 켰을 때 먼 복도와 출입구가 드러났다. 소유자 글로벌 _ElecTorch가 즉시 1로 바뀌는 것도 확인했다. 기본 깊이 경계 18 m, 중앙 손전등 경계 38 m이며 주변은 더 짧게 유지된다.
- 잔해 전체 렌더 경계의 최소 X=-17.76을 확인했다. 우주선 접합 면 X=-18보다 바깥에 있어 회전한 파편도 실내로 돌출하지 않는다.
- PC 렌더 스케일은 0.42→0.65. 기존 저해상도 미술을 유지하면서 CCTV와 중앙 시선의 가독성을 올렸다. 기존 사용자의 Mobile_RPAsset 변경은 수정하지 않았다.
- 증거 파일: Logs/V070/cctv-preview.png, radar-final.png, item-label-final.png, value-loss.png, fracture-final.png, vision-off.png, vision-on.png.
- 테스트 방은 정상 LeaveAsync 후 종료했다. 전체 정산/탈출 E2E와 실제 두 PC·저사양 성능 측정은 수행하지 않았다. 과거 선풍기 운반 E2E 실패를 이번 집중 검증의 성공으로 덮어쓰지 않는다.

## 시각 검토

- Palette discipline: 3/5 — 기존 청록·회청색, 감소 금액만 붉은색으로 구분.
- Style uniformity: 3/5 — 저해상도 환경과 실제 메시 조각, CRT/형광 레이더가 같은 스타일 안에 있음.
- Lighting depth: 3/5 — 손전등 없이 가까운 형태를 읽고 손전등으로 먼 복도를 구분.
- Silhouette: 3/5 — 충전 대상의 얇은 외곽선과 메시 파편에서 원래 물건 형상이 읽힘.
- UI intentionality: 3/5 — 큰 가격을 상호작용 안내와 분리, 레이더 좌표와 신호 일치.
- Feedback visibility: 3/5 — 붉은 감소 금액, 분할 파편과 파열음이 복제된 손실에 반응.
