## 구현 상세와 출처

- [Acerola — The Strange Graphics Of LETHAL COMPANY](https://www.youtube.com/watch?v=Z_-am00EXIc)의 전체 자막 내용과 크롬의 렌더링 설명 장면을 참고했다. 저해상도 렌더, 조명 단계화, 근거리 깊이/밝기 경계, 안개와 후처리의 순서라는 방향을 채택했다. 기존 URP를 유지하며 HDRP 볼류메트릭 구현 자체를 복제하지 않았다.
- 이전의 거리 끝 검은 마스크를 월드 위치 기반 지수형 광학 감쇠로 교체했다. 1.7m 안쪽은 유지하고 기본 밀도 0.255, 손전등 원뿔 안은 0.115를 사용한다. 고정 잘림선 대신 미세한 공간 변화와 픽셀 노이즈로 멀어지는 형체를 약화한다.
- 전체 월드의 반투명 렌더 뒤에 필터를 적용한다. 염력 입자·테두리는 공용 WorldVision 감쇠를, 파편은 URP Forward+ 손전등/그림자와 전체 시야 필터를 사용한다. 가치 표시와 감소 팝업도 같은 감쇠를 따른다.
- 생성 음원 35종 약 93.95초, 2,678크레딧. [음향 설계](../Audio/SOUND_DESIGN.md)와 [원본 파일·게인·출처 목록](../Audio/ElevenLabsManifest.json)을 기록했다. 월드 효과음 풀 32개, 반복 소스 4개, 차폐 저역 필터와 주요 이벤트 시 배경음 감소를 적용했다.
- 문 버튼은 금속 받침·원형 캡·체결부가 있는 형태로 변경하고 벽 표면에 붙였다. 책상/테이블의 낮은 가로대를 제거한 프레임 모델을 생성해 보이는 빈 공간과 충돌체를 맞췄다. CCTV 책상의 전체 하부를 막던 박스도 모델 형태에 맞췄다.
- 운반 중 파손 시 운반자 해제 콜백이 재사용 목록을 변경하던 예외를 발견해, 목록 복사본으로 순회하도록 수정했다.

## 실제 실행 검증

- 이동 유예·중복 공중 점프 방지·착지 전 입력 버퍼·0.62m 틈·안전한 웅크림 유지·빠져나온 뒤 기립 등 7개 검사 통과.
- 실제 배치된 Desk 3개 / Table 3개 모두 진입 → 숨기 판정 → 탈출 → 자동 기립 통과. 최초 모델의 하부 가로대 충돌을 재현한 뒤 프레임 구조를 수정했다.
- 호스트에서 인지 정지 약 0.59~0.70초, 인지 중 피해 없음. 벽 뒤로 숨으면 인지·추격 취소 및 피해 없음.
- 버전 0.8.0 / 프로토콜 6의 별도 호스트와 Player 2 프로세스가 Relay에 참가했다. 참가자에서 인지 true, 추격 true, 플레이어 2명 및 생성 음원 35개를 확인했다.
- 음원 35개 임포트, 무음 없음, 변환 후 최대 피크 -1.5dB, 셰이더 4종 컴파일 메시지 없음. 배경음·우주선 실내음·버튼음의 실제 AudioSource 재생 상태와 염력 입자 52개를 확인했다.
- `Logs/V080/fog-off.png`, `fog-on.png`, `aura.png`, `monster-host.json`, `cover.json`에 실행 증거를 남겼다. Logs는 커밋 대상이 아니다.
- 초기 클라이언트는 이전 0.7.0 설정 때문에 참가가 실패했다. 시나리오 재시작 후 0.8.0으로 일치시켜 재검증했다. 전체 코어 루프 E2E 42단계나 두 물리 PC·6인 장시간 테스트를 통과했다고 주장하지 않는다.

## 최종 추가 검사

- 운반자 2명이 실제로 든 물건에 최종 손상을 적용했다. 호스트에서 예외 없이 파손됐고 별도 참가자에서도 `Broken=true / Holders=0 / Value=0`으로 일치했다.
- 실제 시간으로 진행되는 파편 12개를 확인했다. `Logs/V080/fragments-live.png`, `fragments-off.png`, `fragments-on.png`과 `audio-effects.json`에 증거를 저장했다. 염력 셰이더는 `CoOp/WorldMist`, 생성 음원 35개 모두 Loaded였다.
- 염력 반복음(0.15), 공간 배경음(0.14), 간헐적 공포음의 실제 소스 재생을 확인했다. 공포음과 괴물 경고가 거리 감쇠로 지나치게 묻히지 않게 최소 감쇠 거리를 각각 6m / 3.5m로 조정했다.
- `button-0.png`, `button-1.png`에서 금속 받침·원형 캡·체결부와 벽 부착을 확인했다. 편집기 갱신 함수와 새 씬 생성 양쪽에 같은 형상을 반영했다.
- C# 재컴파일 성공, 음원 WAV 35개와 대응 .meta 35개, 새 에셋의 누락 .meta 없음. 코드·문서 diff 검사 통과. 씬 YAML에는 Unity 직렬화기가 출력한 빈 필드의 공백이 있어 수동 편집하지 않았다.
- 메인/참가자 정상 Leave 후 시나리오 Idle로 종료했다. Unity 에디터는 열린 상태이고 Play는 종료했다. 테스트용 시간 배율·입력·괴물 동결을 해제했다. main 병합·원격 푸시·Windows 빌드는 수행하지 않았다.
