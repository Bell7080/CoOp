# v0.10.0 개발 로그 — 2026-11-27

이전 버전: 0.9.0

## 목표

크리처 3종 행동·공격 기믹, 몬스터 체력(전력)과 배터리, 시계 거미 Tripo 모델

## 변경

- 소음 종류 분리(흡수·발소리·문·무전·알람·충격): 크리처마다 듣는 범위가 다름 (CreatureSenses)
- TV 워커: 빛이 있는 곳만 멀리 봄(어두우면 5m), 손전등 빔에 반응, 1초 예비동작 뒤 방향 고정 돌진, 벽 2.5초·닫힌 문 4초 경직, 주변 CCTV 노이즈
- 선풍기 크롤러: 사이드 테이블 위 진짜 선풍기 모양으로 시작해 코로 빨면 변신, 시야 12m·추적 30m·발소리로 계속 추격, 엄폐·탁자 밑·웅크림 2초여야 어그로 해제, 돌진 뒤 강풍(밀치기·문 열기·통 누출)과 3초 과열
- 자명종 거미: 90초(암전 20초)마다 알람, 어둠·가구 밑도 봄, 등에 매달려 감속·코 봉인 후 5초 뒤 알람(장롱 안은 작게), 동료가 좌클릭 꾹으로 떼기 또는 A/D 흔들기
- 몬스터 체력 = 전력(거미 1000W, 선풍기 3000W, TV 5000W): 언제든 코로 빨 수 있고 플레이어 통에는 1/10만 들어옴, 0이 되면 쓰러져 사라지고 체력 1/5 배터리 드랍(빨기만 가능)
- 발소리·문 버튼·여닫이문·무전/우주선 방송이 소음으로 발생, 피격·강풍 밀치기용 ServerPush, 매달림 감속 SlowRpc
- 시계 거미를 Tripo 모델 + Blender 리깅으로 교체(손으로 만든 버전은 _Unused로 보관), rig_animate.py에 FLOOR 옵션
- 흡수 충전음(Charge) 추가, 가전 흡수 소음 어그로, E2E 스크립트 기대값 갱신
- RoomLimits.ProtocolVersion 6 -> 7 (몬스터 네트워크 상태·RPC 변경)

## 검증과 결과

- Unity 6000.3.29f1 재컴파일 오류 0 (기존 경고 2개만), 씬 빌더로 씬 재생성 후 크리처 3종 종류·배터리·선풍기 위장 배치 스크립트로 확인
- 선풍기 테이블 자리에 다른 콜라이더 겹침 없음, 바닥 NavMesh 확인
