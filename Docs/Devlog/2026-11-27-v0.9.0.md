# v0.9.0 개발 로그 — 2026-11-27

이전 버전: 0.8.0

## 목표

트롤 허용 에너지, 두더지 코 리깅, 랜덤 CCTV와 안 쓰는 에셋 정리

## 변경

- 에너지 통 상한과 송신기에서 빼내는 양 제한 제거 (트롤 플레이 허용)
- 두더지 코 리깅(MoleRig)과 코로 흡수·주입, 공용 발전기·코드선·인벤토리 제거
- 시작 시 맵의 CCTV 카메라 중 랜덤 2개만 켜짐
- 참조되지 않는 에셋 53개를 Assets/_Game/_Unused로 이동(삭제 없음), 지운 스크립트 원본 보관
- CCTV 벽 모니터도 책상 모니터와 같은 CRT 셰이더로 표시해, 캠 전력을 빨면 같은 노이즈가 낌
- 물건 위에 뜨던 가치(W) 표시 제거
- 점프 소리를 직접 합성한 슬라임 느낌으로 교체 (tools/audio/synth_sfx.py)
- 밥솥 모델의 빈 옆면·뒷면을 메움 (tools/blender/fill_prop_holes.py)
- 손전등(세기 9→6.5, 사거리 18→15m)과 전등(65%) 밝기 낮춤
- 송신기 완충 소리는 스테이지에서 처음 채웠을 때만, 모두에게 들리는 축하 차임으로 교체

- 밥솥 모델 앞·옆·뒤 렌더로 구멍 없음 확인
