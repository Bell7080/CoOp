# v0.6.1 개발 로그 — 2026-11-26

이전 버전: 0.6.0

## 목표

CCTV 실물 모니터 연출, 전류 염력과 이동 관용 판정, 우주선 충돌 접합부 개선

## 변경

- CCTV 피드를 실제 3D 화면에 가득 표시하고 플레이어 카메라 접근 및 렌즈 왜곡 적용
- 염력의 단단한 외곽을 재사용 반투명 연무와 약한 전류로 대체
- 0.12초 코요테 타임, 0.14초 점프 버퍼, 낮은 웅크림 캡슐과 안전한 일어서기 판정
- 미리보기 패널을 낮추고 테두리 축소; 외부 문 버튼의 복도 벽 겹침 제거
- 우주선 접합부에 깨진 벽, 찢긴 외판, 철근과 바닥 잔해 배치

## 검증과 결과

- Unity 6000.3.29f1 CLI 컴파일 통과
- 별도 호스트/클라이언트 Relay 연결 및 CCTV 열기/닫기 통과
- 실제 CharacterController로 코요테 점프, 중복 공중점프 방지, 착지 버퍼, 0.62m 틈 통과와 안전한 일어서기 7개 검증 통과
- 양쪽 문 버튼의 물리 겹침 없음 확인
- 플레이 화면 캡처로 CCTV 모니터와 낮춘 미리보기 패널 확인

## 남은 항목

- 전체 E2E는 선풍기 운반 중 복도에서 막혀 중단; 정산/탈출까지 통과한 것으로 주장하지 않음
- 실제 두 PC 테스트와 최종 아트 체감 조정은 미실시
- 시작 시 기존 Unity Multiplayer Play Mode persistent-object 오류가 발생했으나 게임 컴파일 실패는 없음

## 다음 작업

- 위 남은 항목을 확인하고 다음 변경 전 관련 문서를 읽는다.

## 집중 검증 세부 기록

- `Logs/FeelChecks/Movement.cs`를 Unity CLI script eval로 실행했다. 실제 스폰된 소유자 CharacterController를 임시 발판과 0.62 m 높이 통로에서 움직였으며, 테스트 종료 시 위치·입력 상태와 임시 지형을 복구했다.
- 발판 이탈 후 점프, 공중 추가 입력으로 이단 점프 불가, 착지 전 입력, 착지 즉시 점프, 0.54 m 높이/0.24 m 반지름 웅크림, 통로 내부 기립 방지, 통로 밖 자동 기립의 7개 검사가 통과했다.
- 실제 선풍기를 들어 `HeldBy == true`, 연무 입자 52개, 공유 `CurrentMist` 재질을 확인했다. 입자와 전류는 기존 청록 계열을 유지하며 소유권·충전·운반 규칙은 바꾸지 않았다.
- 바깥 버튼의 기존 겹침 대상은 `CorridorWall`이었다. 수정 후 두 버튼 모두 외부 콜라이더 겹침이 없었다.
- 접합부 복도 측벽 끝 1.6 m를 물리적으로 열고 외곽의 보이는 찢긴 외판으로 막았다. 작은 파편에는 콜라이더를 두지 않았으며 기존 중앙 통로와 버튼 접근부는 유지했다. 이 구역의 NavMesh는 중앙 기존 통로를 그대로 사용한다.
- 최종 PlayerSettings.bundleVersion = `0.6.1`, 플레이 모드 종료, 씬 저장 완료, 최종 콘솔 현재 오류 0개를 확인했다. 콘솔을 지우지 않았다.
- 전체 E2E 보고서: `Logs/E2E/20261126-180758/report.md`. 선풍기 운반이 (-7.4, 0.0, 7.1) 부근에서 막혔고 이후 단계는 건너뛰었다. 실패 원인을 이번 변경과 무관하다고 단정하지 않았다.
- 캡처: `Logs/E2E/20261126-180758/03-host-cctv-view.png`, `Logs/FeelChecks/preview-panel.png`, `Logs/FeelChecks/breach-final.png`, `Logs/FeelChecks/aura-final.png`.
- 기존 사용자의 `Assets/Settings/Mobile_RPAsset.asset` 변경은 이번 작업에서 수정하지 않았다. 패키지와 Unity 버전은 변경하지 않았다. 빌드·배포·푸시는 수행하지 않았다.
