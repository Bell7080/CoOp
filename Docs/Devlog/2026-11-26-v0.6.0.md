# v0.6.0 개발 로그 — 2026-11-26

이전 버전: 0.5.0

## 목표

ElecMole: 우주선 상점 터미널·멀티탭·정산 목표·송신기 리프트/모니터, 가전 모델 적용, 방 꾸미기

## 변경

- 우주선 키오스크를 터치 화면 상점(SupplyTerminal)으로 교체: 카테고리 탭(의료품/멀티탭), 휠 스크롤, 보유 금액, 구매 확인/취소, 지원 스테이션으로 배송
- 멀티탭 2/3/5/8구(Blender 제작 모델) 판매: 가전 코드를 꽂고 멀티탭 코드를 송신기에 꽂으면 합산 가치가 정산됨, 전력 불필요
- 송신기: 전력을 넣기 전엔 바닥 아래 대기, 전력 시 상승; 정산 목표 금액·연결 금액 모니터(함께 오르내림); 목표 미달이면 정산 불가
- E 키로 가전 코드 뽑기/꽂기/반납, 무전 키는 V로 이동, 새 플러그·튜브형 코드 모델
- 출발 버튼 캡이 눌려 들어가는 연출, 모델 밖으로 튀어나오던 프리미티브 박스·표시등 숨김
- Tripo 가전(TV·전자레인지·밥솥 등)·외부 CCTV·정산 리프트 모델 적용, 마우스 오버 시 아이템 이름·가치 표시
- 빈 방마다 겹치지 않는 CC0 소품 배치(ElecMoleDecor), 잔소품 흩뿌림 축소, 서버실 정리, 칸막이 방 양쪽 조명, 천장 충돌체, CCTV 책상 화면 맞춤

## 검증과 결과

- 에디터에서 씬 재빌드 후 도달성·터미널 레이캐스트·조명·천장 충돌체·멀티탭 풀/콘센트·출발 버튼 캡 스크립트 검사 통과
- CCTV 화면·가전 모델·상점 화면·송신기 모니터·멀티탭·출발 버튼 눌림·지하 대기 리프트 렌더 확인
- 상점 카테고리 탭·휠 스크롤 변경은 Unity를 끈 상태에서 작성해 컴파일·화면 미확인

## 남은 항목

- 호스트 실플레이 미검증: 구매·배송, E 코드 동작, 멀티탭 정산, 튜브 코드, 모니터 수치, 리프트 상승
- 상점 탭/스크롤 컴파일 및 화면 확인 필요
- 두 프로세스 멀티플레이 테스트 미실시, E2E 미실행
