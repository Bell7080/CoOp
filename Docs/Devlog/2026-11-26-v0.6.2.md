# v0.6.2 개발 로그 — 2026-11-26

이전 버전: 0.6.1

## 목표

플레이어 몸통과 얼굴을 얼린 젤리처럼 형태가 유지되는 탄성으로 조정

## 변경

- 서 있을 때 몸통의 점프 늘어남과 가감속 찌그러짐을 약 70~76% 축소
- 몸통 기울기 상한을 9도에서 2.5도로 축소
- 허리·척추·머리 애니메이션 변형만 각각 35%·22%·15%로 제한
- 손과 코의 기존 애니메이션·스프링은 유지하고 앉으면 0.125초에 걸쳐 몸통 보정을 풀어 기존 말랑한 변형 유지

## 검증과 결과

- Unity CLI 컴파일 통과
- 달리기 애니메이션 60프레임에서 허리 회전 최대 5.98도→2.09도, 척추 6.06도→1.33도, 머리 4.38도→0.66도 확인
- 몸통 보정 전후 손·코 본 10개의 로컬 애니메이션 회전이 동일함을 검증
- 실제 캐릭터 메시 프리뷰 캡처에서 눈과 얼굴 실루엣 유지 확인

## 남은 항목

- 새 멀티플레이 전체 E2E는 수행하지 않음; 시각 표현만 변경
- 앉기 목표와 코·손 스프링 설정은 유지했으며 실제 조작 체감의 최종 미세 조정은 필요할 수 있음

## 다음 작업

- 위 남은 항목을 확인하고 다음 변경 전 관련 문서를 읽는다.

## 추가 검증 기록

- 실제 FBX 달리기 60프레임에서 몸통 보정이 적용됨을 수치와 `Logs/FirmJelly/firm-run.png`로 확인했다. 프리뷰의 손·코 본 10개는 보정 전후 로컬 회전이 같았다.
- 실행 중인 세션에 재컴파일한 뒤 프리뷰 정리·플레이 종료 과정에서 NGO NetworkObject/NetworkBehaviour 정리 NullReferenceException이 다수 발생했다. 이를 게임 컴파일 성공과 구분한다. 오류가 없는 세션이었다고 주장하지 않는다.
- 편집 모드 복귀 후 커서 222710 이후에는 새 오류가 없음을 확인했다. 콘솔은 지우지 않았다. 전체 멀티플레이 회귀 검증은 다시 하지 않았다.
- PlayerSettings.bundleVersion 0.6.2 적용 확인. 임시 프리뷰 오브젝트는 제거했다.
