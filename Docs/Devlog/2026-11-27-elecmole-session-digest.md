## 1. 게임 컨셉 (최종 방향, 2026-11-26 재정의)

- 장르: 2~6인 온라인 협동 공포. PS1식 로우폴리, 픽셀 보이는 텍스처, 붉은 비상등이 있는 폐건물. 분위기 참고: 리썰 컴퍼니, 레포(R.E.P.O.), 벅샷 룰렛 (분위기만, 에셋·캐릭터 복제 금지).
- 배경: 우주선이 망한 지구(폐건물)에 추락해서 시작. 시작 연출은 붉은 경보 → 충돌 → 정전 → 비상전력으로 **밝게** 켜짐(사용자가 "원래대로 밝아지며 = 밝은 상태"라고 명확히 함).
- 플레이어: 말랑하지만 형태감 있는 **두더지 외계인**. 큰 코(코끼리보다 짧음), 흐느적거리는 코와 손, 옷 없는 생물. 한 모델을 플레이어마다 색만 바꿔 씀(레포 방식, 8색 팔레트). 눈은 순하게(하이라이트), 볼터치는 눈 동그라미 바로 아래, 코는 몸 색과 같은 계열 + 가로 줄무늬.
- **핵심 루프 (2026-11-26 12:39 사용자 재정의)**
  - 예전 "가전 충전 → 염력으로 운반 → 코드 꽂아 정산"은 레포/리썰에 불편함만 더한 구조라 **폐기**.
  - 지금: **좌클릭 = 코를 쭉 늘려 가전에 붙여 전력(W)을 빨아 내 에너지 통에 담기**(가전 없어도 코는 늘어남). **우클릭 = 우주선 안 최종 전력 송신기에 주입**. 한 판에 정해진 필요 전력을 채워야 탈출 가능.
  - 가치 단위는 돈이 아니라 **W(전력량)**. 가전마다 실제 소비전력 느낌으로 설계(전기포트 1500W, 전자레인지 1000W, 토스터 800W, 밥솥 650W, TV 120W, 선풍기 50W, 라디오 30W, 전등 60W, CCTV 40W — 세션 당시 값).
  - 흡수는 미니게임 없이 일정 속도(느리게), 스테이지가 오를수록 빨라짐.
  - 우클릭으로 가전·전등·CCTV에 전력을 되돌려 다시 켤 수 있음.
  - 송신기 필요량을 넘긴 전력과 생존자 통에 남은 전력은 돈($)으로 환전 → 상점에서 사용.
  - 송신기가 가득 차도 바로 끝나지 않음. 출발 버튼이 켜지고, 초과 주입·환전을 마친 뒤 플레이어가 자유롭게 출발.
  - 송신기에는 기본 에너지가 조금 들어 있고 빼낼 수도 있음. **트롤 허용**(빼내는 양·통 상한 제한 없음, 2026-11-26 이후 결정, 프로젝트 메모리 참고).
- 전등과 CCTV: 시작 시 켜져 있고, 빨면 기능이 꺼짐(전등은 점점 어두워짐, CCTV는 노이즈가 늘다 끊김). 시작 시 CCTV는 1~2대만 켜짐(이후 랜덤 2대로 확정).
- 가전은 바닥이 아니라 선반·서랍장·탁자 위에 배치.
- 우주선 발전기는 제거, 손잡이는 돌아가지 않는 아이템으로 맵에 배치. 공용 전기 시스템 없음.
- 문: 버튼으로 자유롭게 여닫음(전기 소모 없음, 최종 결정). 여닫이문(양문/외문/단방향)도 있고 몬스터가 몸으로 밀고 다님.
- 숨기: Ctrl로 몸을 구겨 웅크림, 책상·침대·의자 밑으로 기어 들어감(레포처럼 낮은 가구 밑 대부분 들어감), 장롱 안에 들어가 문 닫기. 몬스터 시야(전방 120°) 밖에서 숨거나 엄폐물 뒤로 가면 어그로가 풀림.
- 죽음: 피범벅으로 흐느적거리며 바닥에 퍼진 시체(피 웅덩이는 바닥에 따로 남음). 죽은 사람은 유령으로 동료 관전. 부활은 시체를 보고 **E 길게, 내 체력 30 소모 → 상대 체력 1**. 우주선 안으로 옮긴 시체는 출발 직전 전류로 되살아남.
- 무전: **V 길게**(E는 부활 등 상호작용). 밖에서는 무전기로 우주선에, 우주선 마이크에서는 전원에게. 실제 음성은 아직 미구현(표시와 딸깍 소리만).
- CCTV: 프레디(FNAF)식 관람 모드. 모니터 클릭 → 지도형 카메라 선택(우주선 기점으로 이어짐), 카메라 조명이 비추는 장면, 휘어진 CRT/5점 투시 화면(카메라에 얼굴 들이대는 느낌), 노이즈는 약하게. 오른쪽 화살표로 미니맵 페이지(CCTV 켠 방만, 아군 초록·적 빨강 점). CCTV 책상 뒤 2줄 상황판. 관전 중에도 CCTV가 갱신돼야 함.
- 상점: 우주선 안 **터치 모니터 키오스크**(리썰 컴퍼니 상점 참고). 목록, 가격, 보유 금액, "$X 구매하시겠습니까?" + 확인/취소, 카테고리 탭, 휠 스크롤. 사면 맵의 **지원 스테이션**으로 배송, 외부 인원이 받아 씀. 인벤토리는 1칸에서 시작하고 상점 강화 모듈로 늘릴 예정(인벤토리는 루프 변경 때 제거됨, 재도입 여부 미정).
- 맵: 정해진 나라 맵 몇 개(지금은 **한국 맵**: 장판·카펫 타일·작은 타일·초록 에폭시 바닥, 꽃무늬 벽지, 90년대 한국 가전) 안에서 방 모듈을 랜덤으로 이어 붙임. 통로형(ㅡ ㅣ ㄴ ㅏ +)과 중앙 구조물·칸막이로 나뉜 방을 섞음(리썰/레포 구조 참고). 방은 방답게 꾸미고, 잡동사니는 난잡하게 뿌리지 않음, 같은 소품 중복 배치 금지, 서버실은 깔끔하게. 가구는 플레이어와 비슷하거나 약간 큰 큼직한 로우폴리.
- 화면: PS1식 저해상도·디더·비네트 + 리썰식 깊이 외곽선, 약한 필름 그레인, 약한 색수차. 고글 같은 화면 분할 등 리썰식 기법 허용. 시야 흔들림은 걸을 때 거의 없음, 뛸 때만 아주 약간(멀미 금지).
- 어둠: 기본은 꽤 어둡고 암흑 시야는 좁게, 손전등은 약하게(나중에 강화로 늘림). 대신 천장 전등은 밝고 눈높이 가까이 내려와서 요긴하게 쓰이게.
- UI: 투박하고 레트로, 배경판·장식 없이 깔끔. 설명·안내 글자는 거의 없앰. 키 안내는 `[ LEFT MOUSE ]`처럼 두껍고 짧게, 부드럽게 페이드. 글꼴은 Fusion Pixel(ko/ja/zh, OFL) + 숫자는 DSEG7(OFL). 한·영·중·일 지원 예정.

## 2. 사용자(우성)의 작업 스타일과 선호

- 한국어로 대화. 짧고 구어체로 지시하고, 여러 요청을 번호 목록이나 붙여넣기 덩어리로 한 번에 보냄. 1~n번으로 보내면 **같은 번호로 하나씩 보고**하고, 추가 보고·보완·결정 필요 사항을 따로 적어 달라고 함.
- 중간에 끊겼던 작업을 재개할 때는 "이번 명령에서 했던 것들 하나씩 체크하면서" 하라고 함. 요청이 꼼꼼히 들어갔는지 재확인을 자주 요구함.
- **플레이 테스트는 본인이 직접**. "내가 확인했음 하지마". 작업 후 에디터를 플레이 모드로 켜 두고 넘기면 됨. 자동 입력·텔레포트로 사용자 세션을 조작하지 말 것.
- **E2E는 명령하거나 꼭 필요할 때만**, 돌릴 상황이면 먼저 물어볼 것(2026-11-25).
- 커밋/푸시는 요청할 때만. "메인에 올려줘"라고 하면 팀 규칙대로 버전 올리고 main에 올림(강제 푸시 금지). 작업 브랜치를 원격에 올리면 지우라고 한 적 있음("원격 브랜치 삭제").
- 컴퓨터 전기를 아낌: 자리 비울 때 "유니티는 꺼둔 상태로 유지". 컴퓨터 자체는 켜 둠.
- 디자인 피드백은 직관적이고 구체적("물젤리 말고 딱딱한 젤리", "네모난 히트박스 튀어나와 보임 → 모델 안으로 숨겨"). 도형(placeholder)이 모델 밖으로 보이는 걸 싫어함.
- 비용: Tripo는 예상 크레딧을 보여주고 승인받은 뒤 생성. 가성비 선호(로우폴리 옵션, 리깅·애니메이션은 Blender로 무료).
- 게임 판매 가능성을 염두에 둠: 상업 이용 가능한 라이선스만(CC0 에셋, OFL 폰트, 유료 크레딧 Tripo 모델).
- 결정 질문에는 추천안을 붙여 주면 바로 고름. 결정이 큰 방향 전환일 땐 먼저 의견을 다양하게 물어봄(전기 컨셉 재정의 때).
